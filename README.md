# Verdane Game

A web‑based plant‑versus‑zombie game built with modern front‑end technologies. Players grow and protect their garden while fending off a horde of zombies, using strategic planting and timing to survive.

## Overview

Verdane is a single‑player arcade game that blends the classic “Plant vs. Zombie” concept with a clean, responsive web interface. The game runs entirely in the browser, allowing anyone with a modern browser to play without installing any additional software. It is hosted on GitHub Pages, making it easily accessible and version‑controlled via Git.

## Features

- **Dynamic Plant Growth** – Choose from a variety of plants, each with unique attack patterns and growth speed.  
- **Wave‑Based Zombie Hordes** – Zombies appear in increasing difficulty waves, forcing players to adapt their strategy.  
- **Power‑Ups** – Collect special items such as speed boosters, shields, and extra health to gain a temporary advantage.  
- **Score & Leaderboard** – Track your score and compare it with other players on the built‑in leaderboard.  
- **Responsive Design** – The game looks great on desktop, tablet, and mobile devices, thanks to Tailwind CSS.  
- **Simple Controls** – Use the mouse to plant and click to move, with optional keyboard shortcuts for power‑ups.  
- **Progressive Difficulty** – As the game advances, zombie speed, plant damage, and wave frequency increase.

## Tech Stack

- **HTML5** – Semantic markup for the game UI.  
- **JavaScript (ES6+)** – Core game logic, physics, and interaction handling.  
- **Tailwind CSS** – Utility‑first styling for a modern, responsive look.  
- **Git & GitHub** – Source control and hosting via GitHub Pages.
